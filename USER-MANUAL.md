# Desktop Icon Toggle — user manual

Version 1.5.0

Hide desktop icons for a clean screenshot or recording, then bring everything back. The app does not take screenshots. After icons are hidden, use **Win+Shift+S** or your usual recorder.

## 1. Install

Primary download: **[latest GitHub Release](https://github.com/nchrumka/desktop-icon-toggle/releases/latest)**. The zip is script-only (no `.exe`). Run **Install.bat** so Start menu, tray-at-logon, and uninstall are registered.

1. Download **DesktopIconToggle-1.5.0.zip** from that page.
2. Unzip the folder so `Install.bat` sits next to the scripts, not inside the zip.
3. Double-click **Install.bat**.
4. If SmartScreen says **Windows protected your PC**, choose **More info**, then **Run anyway**.
5. A **Desktop Icon Toggle** window should open.

Install copies the scripts and points Start menu / Startup / Restore Desktop Icons at PowerShell. There is no custom exe in the download. The SHA-256 of the zip is in the GitHub release notes.

If EDR quarantines the install folder, ask IT to allow `%LOCALAPPDATA%\DesktopIconToggle\`.

You do **not** need administrator rights for your own Desktop (including a OneDrive Desktop). The first time a **Public Desktop** icon cannot be hidden, Windows may ask for elevation once. After that, a scheduled task named `DesktopIconToggleHelper` can finish those items without another prompt.

### What install adds

- Start menu: **Desktop Icon Toggle**
- Desktop shortcut: **Restore Desktop Icons** (emergency restore)
- Settings > Apps: uninstall entry
- Tray icon
- Start with Windows (tray only; turn this off in Settings if you do not want it)

Files are copied to `%LOCALAPPDATA%\DesktopIconToggle`.

## 2. First run

Pin the tray icon so you can find it later:

1. Click **^** next to the clock.
2. Drag **Desktop Icon Toggle** onto the taskbar notification area.

Left-click the tray icon (or double-click) to open the window. Right-click for the menu.

Closing the window does **not** quit the app. It stays in the tray.

## 3. Everyday capture

Recommended sequence:

1. Press **Win+Shift+D**, or click **Hide desktop icons** at the bottom of the window (any tab).
   - Hide from the window closes the window first so the app is not in the shot.
2. Press **Win+Shift+S** and snip, or start your recording.
3. Press **Win+Shift+D** again to restore, or use the tray / Home **Restore**.

If the desktop is already hidden, Win+Shift+D restores it.

### Delayed hide

Use this when you need a moment to get another window out of the way.

- Home: **Hide in N seconds**, or **Win+Shift+H**.
- No countdown window stays on screen.
- Press **Win+Shift+D** during the countdown to **cancel**.

### If icons will not come back

Any of these restore the desktop:

- **Win+Shift+D**
- Tray icon > restore
- Home > **Restore desktop icons** or **Show all icons (reset)**
- Desktop shortcut **Restore Desktop Icons**

Reset shows every icon and also restores wallpaper/theme if a capture look was applied, and the taskbar auto-hide setting if it was saved. It clears the saved hide snapshot.

## 4. Home tab

- Status: desktop **visible** or **hidden**
- Delayed hide (if the delay in Settings is greater than 0)
- **Show all icons (reset)**
- Version number

**Hide desktop icons** / **Restore desktop icons** sits at the bottom of the window on every tab, including Look.

## 5. Look tab (wallpaper and theme)

When you **Hide** (not Customize), the app can switch to a clean background and optional light/dark mode. **Restore** puts your real wallpaper and theme back.

| Setting | What it does |
|---------|----------------|
| Apply this look when hiding icons | Master switch (on by default) |
| Wallpaper | Keep yours, light gray, white, black, or a picture you choose |
| Windows light / dark | Keep yours, or force Light / Dark |
| Auto-hide the taskbar while icons are hidden | Off by default. Applies on a fresh Hide only (not Customize Apply). Restore and Reset put the previous auto-hide setting back. Old snapshots without this field are unchanged. The tray can be harder to click while auto-hide is on; use the hide/restore shortcut if it is tucked away. |

Solid colors are generated by the app. A custom picture is filled on **each** monitor (not spanned as one image across all screens).

### Custom picture size

The Look tab shows a **recommended pixel size** from the screens currently attached (native resolution, not the 125%/150% scaling number).

- One monitor: use that width x height.
- Several monitors: size the picture to the screen you will capture. The hint lists each screen and recommends the largest. Extra pixels are cropped on smaller screens.

Use a JPG, PNG, or BMP. Display scaling does not change the pixel size you need.

Look wallpaper/theme and taskbar auto-hide are **not** applied when you use the Customize tab. Old hide sessions from before this feature are left unchanged.

## 6. Customize tab

Checked items **stay visible** on the wallpaper; everything else is hidden. Recycle Bin is not in this list.

- Check the files that should remain, then **Apply now**, or **Hide desktop icons** while this tab is open.
- **Apply now** updates the desktop from this tab. Home **Hide** still hides everything.
- Save / load / delete **layouts** if you often keep the same few icons.
- **Preserve icon positions on restore** restarts Explorer briefly so icons sit where they were. Leave this off unless you need it.

Kept files are shown in their current spots when Windows reports those positions. Restore with **Win+Shift+D**, the tray, or **Restore Desktop Icons**.

## 7. Settings tab

| Option | Default | Notes |
|--------|---------|--------|
| Leave Restore Desktop Icons on the desktop during hide | Off | On = the emergency shortcut stays in the shot |
| Ask before hiding 100 or more icons | On | Only when you click Hide in the window |
| Silence notification toasts while icons are hidden | Off | Helpful for recordings |
| Also hide Recycle Bin, This PC, and Network | Off | System desktop icons, not files |
| Start with Windows (tray only) | On | Uncheck to stop logon startup |
| Hide-in-seconds delay | 3 | 0 turns delayed hide off |
| Auto-restore after minutes | 0 | 0 = off. Restores if you forget |
| Keyboard shortcuts | Win+Shift+D, Win+Shift+H | Restore-only shortcut is optional. Win+Shift+S is reserved |

If a shortcut is already used by another app, Settings tells you. Pick a different key.

## 8. Tray menu

- Open window
- Hide / restore
- Hide after delay
- Show all icons (reset)
- Exit

## 9. What is and is not hidden

**Hidden (files):** shortcuts, documents, folders on your Desktop and on the Public Desktop.

**Not files:** Recycle Bin, This PC, Network — only if you enable that Settings option.

**Never deleted:** the app does not delete your desktop files.

**OneDrive Desktop:** supported. The path is whatever Windows reports as your Desktop folder.

## 10. Uninstall

1. Settings > Apps > **Desktop Icon Toggle**, or run **Uninstall.bat**.
2. Confirm. If icons are currently hidden, they are restored first (including wallpaper/theme from Look).
3. The tray app stops, startup shortcut and Start menu entry go away, and `%LOCALAPPDATA%\DesktopIconToggle` is removed.

## 11. Troubleshooting

**SmartScreen warning**  
More info > Run anyway. Expected for an unsigned GitHub download.

**CrowdStrike / EDR quarantine**  
The GitHub zip has no custom exe. Start menu and Startup run PowerShell scripts. If hide/install still fails, ask IT to allow `%LOCALAPPDATA%\DesktopIconToggle\`.

**Already running**  
Only one copy can run. Use the tray, the hotkey, or Start menu > Desktop Icon Toggle.

**Public Desktop items stay visible**  
Accept the one-time elevation prompt, or hide those items from an elevated session. After the helper task is registered, later hides should cover them.

**Wallpaper did not restore**  
Use **Show all icons (reset)** or the **Restore Desktop Icons** shortcut. Do not delete `snapshot.json` while icons are hidden.

**Tray icon missing**  
Click **^** and pin it. The app can still run from the Start menu or hotkeys.

**Hotkey does nothing**  
Another app owns that combination. Change it on the Settings tab.

**Need a log**  
`%LOCALAPPDATA%\DesktopIconToggle\error.log` if the tray hits an error.

## 12. Command line (optional)

Most people should use the tray. From the install folder, `DesktopIconManager.ps1` supports `-Hide`, `-Restore`, `-Reset`, and `-ClearProfiles`. The desktop **Restore Desktop Icons** shortcut runs `DesktopIconManager.ps1 -Reset`.
